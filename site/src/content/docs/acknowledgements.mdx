**Astro Iconset** is developed and maintained in the open. Issues and contributions are welcome on [GitHub](https://github.com/sudeep2003/astro-iconset).

## Iconify

Icon sets and tooling are powered by [Iconify](https://iconify.design/), which normalizes thousands of open-source icon collections. If Iconify helps your project, consider [supporting the project](https://iconify.design/sponsors/).

## Documentation

This site is built with [Starlight](https://starlight.astro.build/), the documentation toolkit for [Astro](https://astro.build/).
